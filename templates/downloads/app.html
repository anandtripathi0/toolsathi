THE ANDROID APP

Install in a few steps

  1. When an APK is available above, tap Download APK.
  2. Open the downloaded file and allow your browser to install it when Android asks.
  3. Follow Android's installation prompts, then open ToolSathi.
  4. You can turn off your browser's install permission afterwards.

The native app needs an internet connection to reach the tools. Download only from this official page, and compare the checksum if needed.

THE PROGRESSIVE WEB APP

Make a little room on your home screen

On supported browsers, use Install web app when it appears. You can also use your browser's menu:

  1. Android / Chrome: open the menu and choose “Add to Home screen” or “Install app.”
  2. iPhone / Safari: tap Share, then “Add to Home Screen.”
  3. Desktop: use the install icon in your browser's address bar, where available.

File processing and server tools require an internet connection. Offline, the app shows a helpful connection screen.

All public tools remain free. Installing the app is optional.
