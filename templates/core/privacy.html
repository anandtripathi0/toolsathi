How this application handles tool content, files, and optional accounts.

Browser processing

Supported simple tools process content inside your browser. The tool page indicates when browser processing is active. Those inputs are not sent to the processing API. Copy and local file download actions also happen on your device.

Server processing and temporary files

Tools that need Python libraries send your input or upload to the server over the site's connection. Uploaded inputs are processed temporarily and removed after processing. Generated results use unguessable links bound to the browser session that created them. Links expire after 10 minutes. Output files are deleted by the next processing request or the deployment's scheduled cleanup job; production operators should run cleanup every minute. Browser-generated passwords and decoded tokens are never saved on the server.

File size and type checks apply to uploads. Tool content is not intentionally written to application logs. A hosting provider may retain request metadata under its own policies.

Favorites and recently used tools

Your browser's local storage remembers favorite tool IDs and recently visited tool IDs. It does not store your input text, passwords, tokens, private documents, secret keys, or generated results. Use “Clear” in the recently used section to remove that list. Clearing this site's browser storage removes local favorites and history.

Optional accounts and cookies

Accounts are optional. Django session and security cookies support authentication and CSRF protection. Passwords are stored as one-way password hashes. Signed-in accounts synchronize favorites. Recent-tool history only synchronizes when you explicitly enable that preference in your dashboard. Disabling history synchronization removes the server-side recent list.

Usage limits

The server uses request metadata for short-lived rate limiting and security. Reasonable limits protect anonymous access to the tools. This application does not include advertising trackers or third-party behavioral analytics.

Your control

All tools work without an account. You can remove favorites, clear local recent tools, turn off history synchronization, and clear site data in your browser settings. Avoid uploading information you are not authorized to process.

Installed apps

The Android app loads the configured ToolSathi website and requests file access through your device's system picker. It supports downloads you initiate. The web app caches its static interface and offline page; tool inputs and result downloads are not intentionally cached by its service worker.
