# Working tool catalog

83 published tools. Every entry has a working processor, individual page, inputs, validation, practical example and download.

## Developer Tools

- **JSON Formatter** (/tools/json-formatter/) — Beautify JSON with readable indentation and clear syntax errors.
- **JSON Validator** (/tools/json-validator/) — Validate JSON syntax and locate errors by line and column.
- **JSON Minifier** (/tools/json-minifier/) — Remove unnecessary JSON whitespace while preserving its values.
- **JSON Diff** (/tools/json-diff/) — Compare JSON values with a readable unified diff; ignore object key order.
- **JSON to CSV** (/tools/json-to-csv/) — Convert a JSON array of objects into a downloadable CSV table.
- **CSV to JSON** (/tools/csv-to-json/) — Convert a CSV table with headers into a JSON array of objects.
- **YAML to JSON** (/tools/yaml-to-json/) — Convert safe YAML data into formatted JSON.
- **JSON to YAML** (/tools/json-to-yaml/) — Turn valid JSON into clean, readable YAML.
- **XML Formatter** (/tools/xml-formatter/) — Format XML into a more readable layout without executing it.
- **HTML Formatter** (/tools/html-formatter/) — Format HTML into a more readable layout without executing it.
- **CSS Formatter** (/tools/css-formatter/) — Format CSS into a more readable layout without executing it.
- **JavaScript Formatter** (/tools/javascript-formatter/) — Format JavaScript into a more readable layout without executing it.
- **SQL Formatter** (/tools/sql-formatter/) — Format SQL into a more readable layout without executing it.
- **Base64 Encoder/Decoder** (/tools/base64-encoder-decoder/) — Encode UTF-8 text as Base64 or decode Base64 back to text.
- **URL Encoder/Decoder** (/tools/url-encoder-decoder/) — Percent-encode a URL component or decode escaped UTF-8 text.
- **HTML Entity Encoder/Decoder** (/tools/html-entity-encoder-decoder/) — Escape HTML-sensitive characters or decode HTML entities.
- **JWT Decoder** (/tools/jwt-decoder/) — Inspect a JWT header and payload without verifying its signature.
- **Regex Tester** (/tools/regex-tester/) — Find regular-expression matches, positions and capture groups.
- **UUID Generator** (/tools/uuid-generator/) — Generate cryptographically random version 4 UUIDs.
- **Unix Timestamp Converter** (/tools/unix-timestamp-converter/) — Convert Unix seconds or milliseconds to UTC dates and back.
- **Cron Expression Parser** (/tools/cron-expression-parser/) — Preview the next ten occurrences of a five-field cron schedule in UTC.
- **Text Diff Checker** (/tools/text-diff-checker/) — Compare two texts line by line with a unified difference view.
- **SHA-256/SHA-512 Hash Generator** (/tools/hash-generator/) — Compute a SHA-256 or SHA-512 digest of UTF-8 text.
- **Secure Password Generator** (/tools/secure-password-generator/) — Create passwords using cryptographically secure randomness.
- **Markdown Editor** (/tools/markdown-editor/) — Convert Markdown into sanitized HTML with a live result preview.
- **HTML Playground** (/tools/html-playground/) — Preview HTML markup in an isolated, script-disabled browser frame.
- **CSS Playground** (/tools/css-playground/) — Preview your CSS on sample HTML inside an isolated browser frame.
- **HTTP Status Code Reference** (/tools/http-status-code-reference/) — Look up standard HTTP status codes, names and descriptions.
- **User Agent Parser** (/tools/user-agent-parser/) — Identify browser, operating system and device from a user-agent string.
- **UUID Validator** (/tools/uuid-validator/) — Validate a UUID and inspect its canonical form, version and variant.

## Image Tools

- **Image Compressor** (/tools/image-compressor/) — Compress photos to JPEG or WebP, with an optional target file size.
- **Image Resizer** (/tools/image-resizer/) — Resize an image to a bounding box or exact dimensions.
- **JPG to PNG** (/tools/jpg-to-png/) — Convert a JPEG photo into a lossless PNG image.
- **PNG to JPG** (/tools/png-to-jpg/) — Convert PNG images to JPEG, flattening transparency on white.
- **Image to WebP** (/tools/image-to-webp/) — Convert images to compact WebP files.
- **WebP to PNG** (/tools/webp-to-png/) — Convert a WebP image to PNG.
- **Image Cropper** (/tools/image-cropper/) — Crop an image using exact pixel coordinates.
- **Image Rotator** (/tools/image-rotator/) — Rotate an image clockwise by 90, 180 or 270 degrees.
- **Image Quality Reducer** (/tools/image-quality-reducer/) — Reduce JPEG or WebP encoding quality to make smaller files.
- **Signature Resizer** (/tools/signature-resizer/) — Fit a signature inside an exact white canvas without stretching.
- **Image Dimension Checker** (/tools/image-dimension-checker/) — Inspect image dimensions, format and file size.
- **Image Metadata Viewer** (/tools/image-metadata-viewer/) — View image format, dimensions and embedded EXIF metadata.
